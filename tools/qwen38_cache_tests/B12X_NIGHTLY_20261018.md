## Backend switch

Keep existing launch flags and model/cache paths. Add to the target worker:

```bash
export SGLANG_QWEN38_CACHE_W4A16=1
export SGLANG_QWEN38_CACHE_W4A16_BACKEND=b12x
```

The default backend stays `triton`. Roll back B12X by changing the backend to
`triton` and restarting the worker. B12X only handles BF16 decode/verify with
1–3 tokens and top-k <=32; FP16, longer verify and prefill retain the previous
W4A16 path. Draft W4A4 configuration is separate and stays as configured.
B12X launch errors on eligible shapes propagate; they do not silently select
an A4 implementation. Do not set `B12X_W4A16_SMALL_M_DIRECT=0`.

The adapter pins FlashInfer 0.7.2's experimental native ModelOpt interface.
It uses BF16 math with packed FP4 weights and native E4M3 scales. Cache `[up,gate]`
uses B12X `w13` (B12X `w31` would be wrong). Raw global scales are refreshed after
every fill as `g1_alphas * w13_input_scale_quant` and the equivalent for FC2.
No repacked weights, expanded block scales or old pool views are retained.
The runtime still controls fill/read events and expert slot ownership.
Scratch is bounded per layer and allocated before KV sizing: at H=2560/I=640,
512 experts and 170 SMs it is 154,280 tensor bytes/layer (about 7.06 MiB/48 layers),
plus CUDA allocator/event overhead. KV sizing can reflect this small reservation.
The first eager call of each shape compiles its specialization; startup warmup
should precede timed macro measurements. The MoE boundary remains eager on
breakable graph replay; compilation never needs to occur inside its capture stub.

## Checks in the existing image

From the merged checkout:

```bash
tools/qwen38_cache_tests/docker_cpu.sh lmsysorg/sglang:nightly-dev-20261018-b234b5c3

docker run --rm --pull never --network none \
  -v "$PWD:/workspace/sglang:ro" -w /workspace/sglang \
  --entrypoint python3 lmsysorg/sglang:nightly-dev-20261018-b234b5c3 \
  tools/qwen38_cache_tests/b12x_compile_check.py
```

The offline compile check sets SM120a explicitly and supplies mock SM count,
cluster limit and a null driver stream. It compiles 1/2/3 tokens with int32/int64
route IDs at H2560/I640/E112/topk10. It does **not** execute kernels, prove device
occupancy/barrier safety or validate GPU numerical results.

Run GPU parity and microbench before enabling a full worker:

```bash
mkdir -p /tmp/qwen38-b12x-results
docker run --rm --pull never --network none --gpus all --ipc=host \
  -v "$PWD:/workspace/sglang:ro" \
  -v /tmp/qwen38-b12x-results:/results -w /workspace/sglang \
  -e PYTHONPATH=/workspace/sglang/python:/workspace/sglang \
  --entrypoint python3 lmsysorg/sglang:nightly-dev-20261018-b234b5c3 \
  -m tools.qwen38_cache_tests.b12x_gpu_check \
  --output /results/parity-and-latency.json --iterations 100
```

It checks a separately dequantized dense reference, duplicate/invalid/all-invalid
routes, scale changes, graph replay, alternating streams and replacement pool
views. It compares B12X against current Triton fused. Synthetic parity tolerance
is atol=0.004, rtol=0.02; BF16 operation ordering is not promised bit-identical.
Microbench excludes planner, PCIe fill, attention, dense/shared experts and service.
Then compare the merged source with `BACKEND=triton` versus `BACKEND=b12x` using
identical prompts, context, MTP, cache/KV budget, sampling and warmup. Also compare
old offload versus merged+triton separately to distinguish main's effect.
Record sustained throughput, TPOT, acceptance length, verify/project/fill timings,
cache slots and KV tokens. No performance improvement is claimed until GPU/macro
results exist.

## Merge adaptation

Main adds FFN stage boundaries and HC norm handoffs. The merged Qwen4 execution
scopes prefill/decode/verify at the new FFN boundary and calls offload shared/fill
overlap there. Overlap honors `reduce_results=False` so the new boundary owns the
sum. Main's monokernel initialization, draft KV pool finalization and quantized
RL reload guard are preserved alongside offload memory probes. Existing AST test
fixtures now supply main's short-conv verify row helper and reload guard.
