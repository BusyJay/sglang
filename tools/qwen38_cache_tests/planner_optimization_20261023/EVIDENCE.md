The scripts set the same runtime environment and base server command for both revisions. `run_serving.py NAME [--before] [--n 0|1] [--gpu] [--short] [--no-spec]` launches the existing full-model streaming benchmark and terminates only its own benchmark server. It refuses to replace a saved performance.json. `--gpu` is the original layered GPU-only path, not the global hybrid cache. `--no-spec` removes all NEXTN flags, leaving the paired configuration otherwise identical. Compare within each pair, not absolute rates between MTP and non-MTP.

Run `before-n1-full --before` first; `run_matrix.py` waits for it and then executes the other serving pairs, followed by before/after frozen planner benchmarks. `finish_validation.py` waits for those planner benchmarks, then runs a no-MTP serving pair and the registered regression tests. Do not launch these coordinators a second time over existing measurements. All GPU benchmarks run serially; CPU operator, pool and quantization changes are deliberately excluded from this optimization.

`bench_planner.py` reads its implementation from PYTHONPATH. It resets identical state inside a captured graph before each planner call, so graph timings include the identical reset costs. Separate small CUDA profiler traces measure only decode_plan_kernel durations. It hashes defined output/state fields, excluding unused plan capacity and the unrelated uninitialized prefill plan. Additional 64-step chains exercise cumulative heat, repeated admission and cache migration. Snapshots and raw traces remain local for debugging.

Tracked evidence includes summaries, state hashes, commands, condensed performance summaries and reproduction scripts. Raw performance JSON/streams, server/test logs, CUDA profiler traces and .pt debug snapshots remain local; no weight or native binary is committed. `source-manifest.json` records source hashes, the before revision and validation status. Test results concern this change; they are not a new full-model quality evaluation or a claim that CPU co-compute alone causes the entire throughput change.
